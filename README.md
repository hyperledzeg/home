# HyperLed

Télécommande non officielle pour Hyperion — contrôle local de votre éclairage d'ambiance.

**Gratuit • Sans publicité • Sans traqueur • Sans collecte de données**

---

## 📥 Télécharger

➡️ **[Dernière version (APK)](https://github.com/hyperledzeg/home/releases/latest)**

### Installation
1. Téléchargez le fichier `.apk` depuis la page Releases.
2. Sur Android, autorisez l'installation depuis une source inconnue si demandé.
3. Ouvrez le fichier pour installer l'application.

> Compatible avec [Obtainium](https://github.com/ImranR98/Obtainium) pour les mises à jour automatiques.

## ℹ️ À propos

HyperLed est une application indépendante permettant de piloter un éclairage d'ambiance géré par le logiciel libre [Hyperion](https://github.com/hyperion-project/hyperion.ng).  
Elle n'est affiliée ni au projet Hyperion ni à ses développeurs.
